Final Project Instructions: Database Development, Database Connectivity, and Web Application Deployment

Project Task

Develop, connect, and deploy a functional database-driven web application.

I General Instructions

For your Final Project, you are required to develop a web application that uses a database to store, retrieve, update, and manage information. You must complete the following three major tasks:

1

Database Creation

Create your project database using either XAMPP (MySQL/MariaDB with phpMyAdmin) or MySQL Server.

2

Database Connectivity

Connect your database to your web application using PHP or another programming language or technology that supports database connectivity.

3

Web Hosting & Deployment

Publish your completed web application using Hostinger so that it can be accessed through an online URL.

Expected Final Output

A properly structured database
A functional web app connected to DB
Working CRUD operations
Deployed website hosted on Hostinger
Complete project documentation and submission requirements
Phase 01

Part 1. Database Creation

You may choose either of the following approaches to create your database. Choose only one method, depending on your available tools and development environment.

Required Tools (Option A)

XAMPP Web Browser (Google Chrome, Firefox, etc.) Visual Studio Code or another code editor

Step 1. Install XAMPP

  1. Visit the official Apache Friends website: https://www.apachefriends.org/
  2. Download the XAMPP installer compatible with your operating system.
  3. Run the installer.
  4. Select the following components:
    Apache MySQL (MariaDB) PHP phpMyAdmin
  5. Complete the installation and open the XAMPP Control Panel.

Step 2. Start Apache and MySQL

  1. Open the XAMPP Control Panel.
  2. Locate Apache and click Start.
  3. Locate MySQL and click Start.
  4. Make sure both services are running (highlighted green).

Step 3. Open phpMyAdmin

  1. Open your web browser.
  2. Enter the following URL and press Enter:
    http://localhost/phpmyadmin
  3. The phpMyAdmin interface should appear.

Step 4. Create Your Database

  1. In phpMyAdmin, click the New option on the left panel.
  2. Enter your database name (Example: student_management_system).
  3. Select the collation utf8mb4_general_ci if available.
  4. Click Create. Your database should now appear in the left panel.
Important: Use lowercase letters and underscores for database names. Avoid spaces and special characters.

Step 5. Create Your Database Tables

  1. Click the database you created and locate the Create table section.
  2. Enter the table name, specify the number of columns, and click Create.
  3. Define the necessary fields and their data types (Example: students table):
Field Data Type Description
id INT Primary key (Enable AUTO_INCREMENT)
student_number VARCHAR(20) Student number
first_name VARCHAR(100) First name
last_name VARCHAR(100) Last name
email VARCHAR(150) Email address
created_at TIMESTAMP Date created

Set id as the PRIMARY KEY, enable AUTO_INCREMENT for the id field, and click Save.

Step 6. Insert Sample Records

  1. Select the students table.
  2. Click the Insert tab.
  3. Enter sample student information and click Go.
  4. Repeat until you have at least five sample records.

Step 7. Verify Your Database

  1. Click the students table.
  2. Select the Browse tab to check if records were saved.
  3. Review the table structure under the Structure tab.
Expected Result: Your database should contain the required tables, properly defined fields, primary keys, and sample records.

Required Tools (Option B)

MySQL Community Server MySQL Workbench Visual Studio Code or another code editor

Step 1. Download & Install MySQL

  1. Visit https://dev.mysql.com/downloads/
  2. Download MySQL Installer for your OS and run it.
  3. Select MySQL Server and MySQL Workbench.
  4. Choose default port 3306 and create a root password.
Important: Remember your MySQL username and password. You will need these credentials when connecting your application.

Step 2. Open MySQL Workbench

  1. Launch MySQL Workbench.
  2. Locate the MySQL connection created during installation.
  3. Click the connection and enter your root password.
  4. Wait for the SQL Editor to open.

Step 3. Create Your Database

Open a new SQL query tab, enter the commands below, and click the lightning icon or press Ctrl + Enter:

CREATE DATABASE student_management_system;
USE student_management_system;

Step 4. Create Your Table

CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    student_number VARCHAR(20) NOT NULL,
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    email VARCHAR(150),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Step 5. Insert Sample Records

Step 6. Retrieve & Verify Records

SELECT * FROM students;

Check the output panel. It should display the five records you inserted.

Step 7. Verify Database Structure

SHOW TABLES;
DESCRIBE students;

Make sure that the database and table were successfully created.

Expected Result: Your MySQL Server should contain the database, table structure, primary key, and sample records.
Phase 02

Part 2. Database Connectivity & CRUD

After creating your database, connect it to your web application so users can submit information through forms and retrieve, modify, or delete stored records.

Step 1. Prepare Your Project Folder

Open Visual Studio Code, create a folder for your project (e.g., student-management-system), and organize your files: 

student-management-system/
│
├── index.php
├── dashboard.php
├── students.php
├── add_student.php
├── edit_student.php
├── delete_student.php
│
├── config/
│   └── database.php
│
├── assets/
│   ├── css/
│   ├── js/
│   └── images/
│
└── database/
    └── student_management_system.sql

Directory Breakdown

  • config/database.php — Stores PDO database connection settings.
  • students.php / add / edit / delete — Dedicated CRUD handlers & UI pages.
  • assets/ — Organizes stylesheets, client scripts, and images.
  • database/*.sql — Holds your exported SQL schema & seed data.

Note: You may use a different folder structure depending on your project's requirements and programming language.

Steps 2 – 4. Connection Configuration, Testing & Data Retrieval

Explore the PHP PDO implementation files below. Click any tab to inspect and copy the code.

config/database.php (PHP PDO) 
<?php

$host = "localhost";
$dbname = "student_management_system";
$username = "root";
$password = "";

try {

    $conn = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8mb4",
        $username,
        $password
    );

    $conn->setAttribute(
        PDO::ATTR_ERRMODE,
        PDO::ERRMODE_EXCEPTION
    );

    echo "Database connected successfully!";

} catch (PDOException $e) {

    die("Database connection failed.");

}

?>
Code Purpose
$hostDatabase server address
$dbnameName of your database
$usernameDatabase username
$passwordDatabase password
new PDO()Establishes the database connection
try-catchHandles possible connection errors
Important: For a local XAMPP installation, the usual default credentials are root with an empty password (""). For MySQL Server, use the username and password configured during installation.
test_connection.php 
<?php

require_once "config/database.php";

echo "Your application is now connected to the database!";

?>

How to Test Locally (XAMPP):

  1. Place your project folder inside C:\xampp\htdocs\
  2. Start Apache and MySQL using the XAMPP Control Panel.
  3. Open your browser and enter: http://localhost/student-management-system/test_connection.php

Expected Result: The browser should display a successful database connection message.

students.php (Retrieve Data from Database) 
<?php

require_once "config/database.php";

$sql = "SELECT * FROM students";
$stmt = $conn->prepare($sql);
$stmt->execute();
$students = $stmt->fetchAll(PDO::FETCH_ASSOC);

?>

<!DOCTYPE html>
<html>
<head>
    <title>Student Records</title>
</head>
<body>

    <h1>Student Records</h1>

    <table border="1" cellpadding="10">
        <tr>
            <th>ID</th>
            <th>Student Number</th>
            <th>Name</th>
            <th>Email</th>
        </tr>

        <?php foreach ($students as $student): ?>
        <tr>
            <td><?= htmlspecialchars($student['id']) ?></td>
            <td><?= htmlspecialchars($student['student_number']) ?></td>
            <td>
                <?= htmlspecialchars($student['first_name']) ?>
                <?= htmlspecialchars($student['last_name']) ?>
            </td>
            <td><?= htmlspecialchars($student['email'] ?? '') ?></td>
        </tr>
        <?php endforeach; ?>
    </table>

</body>
</html>

Open http://localhost/student-management-system/students.php. If the connection works, your browser will display the records stored in your students table.

Phase 03

Part 3. Hosting and Deployment Using Hostinger

After completing and testing your web application locally, deploy it online using Hostinger so it is accessible through a public website URL rather than only through localhost.

Required Materials: Completed web application Database backup file (.sql) Hostinger hosting account Domain name or assigned hosting domain
1

Prepare Your Project & Export Database (.sql)

Open your project folder in Visual Studio Code, remove unnecessary/temporary/debugging scripts, verify all asset links and CRUD operations, and export your database backup (e.g., student_management_system.sql):

Via XAMPP / phpMyAdmin

  1. Open http://localhost/phpmyadmin
  2. Select your project database.
  3. Click the Export tab.
  4. Select Quick as the export method and SQL as format.
  5. Click Export and save the .sql file.

Via MySQL Workbench

  1. Open MySQL Workbench & connect to server.
  2. Select Server → Data Export.
  3. Select your project database.
  4. Choose Export to Self-Contained File.
  5. Specify filename/location and click Start Export.
2

Log in to Hostinger

Visit https://www.hostinger.com/, log in, open your hosting dashboard, and select your target website/domain.

3

Upload Your Web Application to public_html

  1. Navigate to Websites → Manage site → Files → File Manager.
  2. Open the public_html folder of your selected domain.
  3. Compress your project files into a ZIP archive, upload it, right-click the archive, and select Extract.
  4. Ensure that the actual project files are placed directly inside public_html.
✓ Correct Structure 
public_html/
├── index.php
├── dashboard.php
├── students.php
├── config/
│   └── database.php
└── assets/
✗ Avoid Nested Folder 
public_html/
└── student-management-system/
    └── index.php
# Causes unwanted subdirectory URL
4

Create a Database in Hostinger

Your local database does not transfer automatically. Go to Websites → Manage site → Databases → Management, enter a database name, create a database username, set a strong password, and click Create.

Required Information Example Only
Database HostHostinger-provided hostname (Do not assume localhost)
Database Nameaccountprefix_studentdb
Database Usernameaccountprefix_studentuser
Database PasswordYour assigned password
5

Import Your Local Database into Hostinger

In Databases → Management, click Enter phpMyAdmin beside your new database, select the database, open the Import tab, choose your exported .sql file, and click Import / Go.

Important: Hostinger's phpMyAdmin import limit is currently 256 MB. If you encounter an import error, check the SQL file for unsupported commands, permissions, or size limits.
6

Update Your Database Connection Settings

Compare Local XAMPP vs. Production Hostinger configuration

Production config/database.php (Hostinger) 
<?php

$host = "YOUR_HOSTINGER_DATABASE_HOST";
$dbname = "YOUR_HOSTINGER_DATABASE_NAME";
$username = "YOUR_HOSTINGER_DATABASE_USERNAME";
$password = "YOUR_HOSTINGER_DATABASE_PASSWORD";

try {

    $conn = new PDO(
        "mysql:host=$host;dbname=$dbname;charset=utf8mb4",
        $username,
        $password
    );

    $conn->setAttribute(
        PDO::ATTR_ERRMODE,
        PDO::ERRMODE_EXCEPTION
    );

} catch (PDOException $e) {

    error_log($e->getMessage());

    die("Unable to connect to the database.");

}

?>
Local Development config/database.php (XAMPP) 
$host = "localhost";
$dbname = "student_management_system";
$username = "root";
$password = "";

Replace placeholder values with your actual Hostinger credentials. Do not upload local credentials as your production configuration.

7

Test Your Deployed Website

Open your domain name in a browser, verify the homepage loads, test login/registration, perform Create, Read, Update, and Delete operations directly against the Hostinger database, check all CSS/JS/image assets, and test on both desktop and mobile devices.

8

Configure Domain & SSL Certificate

Ensure your domain DNS records point to Hostinger, navigate to the SSL section in your Hostinger dashboard, activate your SSL certificate, and verify secure access via https://yourdomain.com.

          Guidelines & Integrity
          
Part 5. Important Reminders

        


        

          

            

              
1. Use your own project

              
Your database must be relevant to the actual purpose and functionality of your proposed system.

            

            

              
2. Do not use unrelated sample databases

              
The sample database provided in this instruction is only for demonstration.

            

            

              
3. Test before deployment

              
Make sure your application works locally before uploading it to Hostinger.

            

            

              
4. Secure your credentials

              
Never publicly expose your database username and password.

            

            

              
5. Do not rely on screenshots alone

              
Your instructor must be able to access and test the actual deployed website.

            

            

              
6. Ensure database consistency

              
Changes made through your web application must be reflected in your hosted database.

            

            

              
7. Maintain your source code

              
Keep a copy of your original project files and database backup.

            

            

              
8. Be prepared for project demonstration

              
You must be able to explain how your database works, how it connects to your application, and how your system is deployed.

            

          


          

            Note for projects using Node.js, Python, Java, or other backend technologies: Before choosing your hosting environment, verify that your Hostinger plan supports the required runtime and deployment configuration. The PHP/MySQL procedure above is intended for conventional web hosting. Other backend technologies may require a different hosting plan or deployment method.
