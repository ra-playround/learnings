CREATE DATABASE IF NOT EXISTS student_management_system
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_general_ci;

CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    student_number VARCHAR(20) NOT NULL UNIQUE,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

<?php
// db.php — Database Connection Using PDO
$host     = 'localhost';
$dbname   = 'student_management_system';
$username = 'root';
$password = ''; // Default XAMPP password is empty

try {
    $dsn = "mysql:host=$host;dbname=$dbname;charset=utf8mb4";
    $pdo = new PDO($dsn, $username, $password, [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES   => false,
    ]);
} catch (PDOException $e) {
    die("Database connection failed: " . htmlspecialchars($e->getMessage()));
}
?>

Step 1

Access Hostinger Account

Log in to hostinger.com (use your student hosting plan or domain) and open hPanel.

Step 2

Create Online MySQL DB

Go to Databases → Management. Create a database, username, and strong password. Record all credentials carefully.

Step 3

Export Local Database

Open local phpMyAdmin, select student_management_system, click Export → Quick → SQL, and download .sql.

Step 4

Import to Hostinger

In Hostinger phpMyAdmin, select your new database, click Import, upload your .sql file, and execute.

Step 5

Upload Files to public_html

Open Files → File Manager, navigate into public_html/, and upload your PHP project files.

Step 6

Update db.php Credentials

Edit db.php on Hostinger to use your live Hostinger database name, username, and password.

Step 7

Test Live Website

Visit https://yourdomain.com/students.php and verify records load cleanly with zero PHP warnings.

Step 8

Enable SSL / HTTPS

In hPanel Security → SSL, verify your SSL certificate is active so your URL loads securely over https://.

        Part 5 — Quality & Security
        
Important Reminders

      


      

        

          

             Keep Hosting Active
          

          
Ensure your Hostinger website remains online and accessible until grading is completed.

        


        

          

             Protect Credentials
          

          
Never share your Hostinger account password or expose raw database passwords publicly.

        


        

          

             Use Prepared Statements
          

          
Always use PDO prepared statements (prepare() & execute()) for user inputs to prevent SQL injection.

        


        

          

             Verify ZIP Archive
          

          
Test extracting your .zip file before uploading to confirm all 4 deliverables are inside.
